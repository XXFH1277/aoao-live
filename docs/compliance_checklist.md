# AI 数字人直播合规清单

适用阶段：螯螯 Demo、抖音测试直播、客户演示。

## 直播前

- [ ] 直播标题或简介包含“AI 数字人”或“AI 主播”。
- [ ] 画面持续显示“AI 主播 / AI 生成”角标。
- [ ] 开播前 30 秒内口播：本直播间由 AI 数字人主播讲解，并有真人助理实时监管。
- [ ] 不宣称或暗示主播是真人。
- [ ] 商品话术已删除绝对化承诺、医疗功效、绕平台交易等高风险表达。
- [ ] 真人助理已在场，能暂停、接管、回复复杂问题。
- [ ] 试播前复查平台 AI 内容声明入口或报备要求。

## 直播中

- [ ] 角标持续可见，没有被贴片、商品卡或字幕遮挡。
- [ ] 遇到售后、退款、价格、库存、投诉、政策类问题时，交给真人助理。
- [ ] 不编造库存、资质、检测报告、航班船班、天气、房态。
- [ ] 出现模型异常、敏感内容、平台警告时立即暂停 AI 输出。
- [ ] 保留直播录像和控制台日志，方便复盘。

## 直播后

- [ ] 记录直播时长、接管次数、故障次数、平台提示。
- [ ] 记录观众高频问题，补充到话术池。
- [ ] 记录 API token 用量和实际费用。
- [ ] 更新禁忌词表和人工接管规则。
