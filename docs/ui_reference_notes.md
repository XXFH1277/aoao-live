# 中控台 UI 参考与重构方向

更新日期：2026-05-24

## 参考方向

- Robo-Stream / obs-web：参考 OBS 远程控制、场景/来源管理、状态反馈。
- SAMMI：参考直播自动化、互动触发器、事件动作、日志。
- MOLTSTREAM / AI virtual streamer 项目：参考 LLM、TTS、Avatar、OBS 的运行链路。
- Shadcn Admin / Tailwind Admin：参考现代后台的信息密度、侧边栏、卡片、表单和状态标签。

## 本项目不照搬的点

- 不做纯 OBS 遥控器，因为我们的核心是 AI 数字人带货。
- 不做营销落地页，因为第一屏应该是可操作的直播工作台。
- 不做全自动无人值守，因为合规方案要求真人助理监管。

## 当前 UI 模块

- 工作台：直播间卡片、新建直播间入口。
- 模特/声音：数字人、声音、模型、输出模式状态。
- 智能脚本：商品知识、人设约束、AI 回复、去敏感词流程。
- 商品知识库：商品/场景、知识条目、保护规则统计。
- 主动互动控制：模拟弹幕、人工接管、话术控制。
- OBS 工具：WebSocket 连接、创建字幕源、刷新字幕源。
- 保护配置：AI 身份声明、真人接管、禁忌词过滤、隐式标识待办。
- 底部开播栏：平台、直播间地址、弹幕捕获、保存、开始直播。

## 下一轮 UI 要补

- 直播间列表独立页面，而不是当前同屏展示。
- 商品知识库可编辑表格。
- 互动队列：显示弹幕、AI 建议回复、人工确认、忽略。
- OBS 场景/来源列表。
- 开播前检查清单。
- 试播复盘页面。
