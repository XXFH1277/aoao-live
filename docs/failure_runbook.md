# 故障排查手册

## 直播画面无角标

1. 检查 OBS 浏览器源 URL 是否为 `http://127.0.0.1:8787/overlay`。
2. 检查控制台服务是否运行。
3. 刷新浏览器源缓存。
4. 确认浏览器源层级在背景和数字人上方。

## 话术不动

1. 打开 `http://127.0.0.1:8787`。
2. 确认状态不是 `paused`。
3. 点击“继续”或“下一句”。
4. 检查 `scripts/aoao_mainline.txt` 是否为空。

## 弹幕回复不合适

1. 立即点击“暂停”。
2. 用“人工接管回复”输入真人确认后的回答。
3. 将问题记录到复盘表。
4. 必要时把关键词加入 `configs/forbidden_terms.txt` 或人设接管规则。

## OBS 推流卡顿

1. 降低 OBS 输出码率和分辨率。
2. 暂停 AI 话术，保留静态画面和角标。
3. 检查网络上行和 GPU 占用。
4. 如果数字人引擎占满显存，改用预生成视频 + 实时字幕的降级方案。

## 平台出现违规提示

1. 立即暂停 AI 输出。
2. 截图并记录提示内容和时间。
3. 检查是否缺少 AI 标识、是否出现敏感词、是否暗示真人身份。
4. 当场改话术，必要时停止试播。
