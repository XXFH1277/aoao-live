# 螯螯 AI 数字人直播 Demo 工作台

这个文件夹现在是“30 天低成本验证计划”的执行工作台。目标不是先做完整 SaaS，而是先把螯螯自有 IP 的抖音测试直播流程跑通：AI 主播话术、真人助理监管、显式 AI 标识、试播记录和复盘。

## 当前已落地

- `src/aoao_live_console.py`：最小本地助理控制台，支持话术轮播、暂停/继续、下一句、模拟弹幕、人工接管回复、OBS 浏览器源角标/字幕。
- `configs/persona.json`：螯螯人设、口头禅、合规声明、接管规则。
- `configs/products.yaml`：第一版商品库和卖点话术。
- `configs/forbidden_terms.txt`：直播禁忌词和高风险表达清单。
- `scripts/aoao_mainline.txt`：30-60 分钟话术轮播素材的起始版本。
- `docs/`：合规清单、环境记录、故障手册、试播复盘表、30 天执行表、资料依据。

## 本地运行

需要 Python 3.10+。本控制台只使用标准库，不需要安装依赖。

```powershell
.\run_console.ps1
```

打开：

- 助理控制台：http://127.0.0.1:8787
- OBS 浏览器源：http://127.0.0.1:8787/overlay

OBS 建议先添加一个“浏览器源”，URL 填 `/overlay` 地址，宽高设为 `1920x1080`。正式试播前，画面里必须持续可见“AI 主播 / AI 生成”标识。

## 30 天验收口径

1. 螯螯能连续播 30-60 分钟，不依赖临场写稿。
2. 真人助理可以随时暂停、切换话术、人工回复。
3. 画面和口播明确声明 AI 身份，不冒充真人。
4. 每次试播都记录环境、故障、成本和复盘结论。

## 下一步接入点

- 数字人形象层：优先 HeyGem，备选 LiveTalking。
- 声音层：优先 GPT-SoVITS 或 CosyVoice2。
- LLM：本地小模型做分类/模板回复，DeepSeek API 只处理复杂弹幕。
- 抖音：先用测试直播间验证，不承诺无人直播，不做矩阵推流。
